# Waitlist V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Accountless per-tier sold-out demand, observed restock notification, secure leave, and owner demand management without inventory ownership.

**Architecture:** Read-only canonical inventory extraction followed by a private Waitlist lifecycle/delivery domain. Bounded observational workers share the existing ticketing lock boundary, while all provider calls run outside transactions. Existing ticket and organizer domain ledgers stay separate.

**Tech Stack:** PostgreSQL/Supabase migrations and RPCs, Deno Edge Functions, React/TypeScript, React Email, Vitest/Playwright, Python local PostgreSQL concurrency harnesses.

**Spec:** `Docs/specs/waitlist-v1-inspect-spec.md`; detailed governing approval `Docs/specs/waitlist-v1-build-approval.md`.

## Interface contract

`private.ticket_tier_inventory(uuid,timestamptz)` returns table `(tier_id uuid,event_id uuid,quantity_total integer,protected_quantity bigint,availability_status text)`; no writes. Public projection passes statement_timestamp; Waitlist passes clock_timestamp after locks.

Public HTTP join exact fields `{eventId,tierId,name,email,requestId}`; result `{kind:'joined'|'TICKETS_AVAILABLE'|'WAITLIST_UNAVAILABLE'|'INVALID_INPUT'|'RATE_LIMITED'}`. HTTP leave exact `{token}`; result `{kind:'removed'|'unavailable'|'rate_limited'}`. Token never returned by join.

Server RPCs use snake-case `p_` fields: `server_join_waitlist(p_event_id,p_tier_id,p_name,p_email,p_request_id,p_ip_hash)`; `server_leave_waitlist(p_token_hash,p_ip_hash)`; `server_observe_waitlist(p_tier_id)`; `server_next_waitlist_tiers(p_limit)` returns UUID array. Observer transaction returns `{kind,cycle,processed,more}`.

Owner RPCs `get_owned_waitlist(p_event_id,p_tier_id default null,p_cursor default null)` → `{tiers:[{id,name,waiting,closed}],entries:[{id,name,email,joinedAt,status}],nextCursor,closed}`; `remove_owned_waitlist(p_event_id,p_tier_id,p_enrollment_id)` → boolean. `get_public_waitlist_capability(p_event_id)` → `{enabled,eligible}` with no demand counts.

Delivery RPCs: `server_claim_waitlist_delivery()` → `{attemptId,leaseId,payload}` or null; `server_prepare_waitlist_delivery(p_attempt_id,p_lease_id)` → server-owned facts/recipient/current payload; `server_save_waitlist_payload(p_attempt_id,p_lease_id,p_payload,p_token_hash)` → boolean; `server_begin_waitlist_dispatch(p_attempt_id,p_lease_id)` → immutable payload/key/lease/retry facts or null; `server_finish_waitlist_dispatch(p_attempt_id,p_lease_id,p_outcome,p_provider_id)` → boolean. `server_stop_waitlist_delivery(p_attempt_id,p_lease_id,p_reason)` preserves possible dispatch. Settings/configure/health/prune service-only.
