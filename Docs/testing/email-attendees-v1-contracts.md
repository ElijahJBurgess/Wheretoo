# Email Attendees V1 database contracts

All owner RPCs execute as authenticated JWT owner and return JSON. Options/submit/receipt and unauthorized preview throw P0001 with sanitized uppercase code. An authorized preview returns success OR `{error:{code:string}}` for a domain rejection, so its preview-request admission is committed even when rejected. Callers must inspect this result before treating it as a preview. All service RPCs are service_role-only. No direct private table access. UUID arguments use PostgreSQL uuid. Times are ISO timestamps; options deadline is null for absent/nonfinite schedules. Selectors are exact `{kind:'everyone'}` or `{kind:'tier'|'order'|'registration',id:UUID}`; no additional properties.

Owner RPCs:
- `get_owned_organizer_message_options(p_event_id)` → `{eventId,admissionType,deadline,canSend,reason,replyTo,tiers:[{id,name,archived}]}`.
- `preview_owned_organizer_message(p_event_id,p_selector jsonb,p_subject text,p_body text)` → `{recipientCount,canSend,reason,audienceLabel,deadline,fingerprint,subject,body,facts}`. Empty Everyone returns recipientCount:0, canSend:false, reason:NO_RECIPIENTS; submit rejects zero. Inactive individual returns structured INACTIVE_INDIVIDUAL. facts is `{eventId,eventName,organizerName,startsAt,endsAt,timezone,venueName,senderEmail,replyTo,templateVersion,eventUrl,flyerUrl,organizerLogoUrl}`. Optional URL facts are null when omitted. Preview never includes addresses. Content normalized in DB: subject outer ASCII spaces trimmed; body CRLF/CR becomes LF and outer spaces/tabs/LF trimmed. No content transformation on delivery.
- `submit_owned_organizer_message(p_event_id,p_selector,p_subject,p_body,p_fingerprint text,p_request_id uuid)` → `{messageId,requestId,queuedRecipients,confirmedAt}`. Exact request replay returns original receipt before new-send gates.
- `get_owned_organizer_message_receipt(p_event_id,p_request_id)` → receipt or null; null is not authorization to create a new UUID.

Worker RPCs:
- `server_claim_organizer_message_recipient()` → null or `{attemptId,leaseId,payload}`. Two-minute lease.
- `server_prepare_organizer_message_recipient(p_attempt_id,p_lease_id)` → null or `{attemptId,messageId,recipient,subject,body,facts,payload}`. One private destination only; no grant.
- `server_save_organizer_message_payload(p_attempt_id,p_lease_id,p_payload jsonb)` → boolean. Standard immutable encrypted envelope `{version:1,keyId,nonce,ciphertext}`.
- `server_begin_organizer_message_dispatch(p_attempt_id,p_lease_id)` → null or `{attemptId,payload,idempotencyKey,leaseUntil,firstPossibleDispatchAt,dispatchCount}`. Commit before provider. Stable key `organizer-message/<attemptId>`.
- `server_finish_organizer_message_dispatch(p_attempt_id,p_lease_id,p_outcome text,p_provider_id text default null)` → boolean. Outcomes accepted/failed/unknown. Prior uncertainty cannot be erased by later rejection.
- `server_stop_organizer_message_recipient(p_attempt_id,p_lease_id,p_reason text)` → boolean; reason configuration_unavailable/support_unconfigured/payload_unreadable/invalid_projection.
- `server_observe_email(p_webhook_id text,p_attempt_id uuid,p_provider_id text,p_kind text,p_observed_at timestamptz)` → boolean. Signature verification must precede invocation. Routes exact UUID to one ledger only; false on ambiguity/conflicting replay/provider binding.
- `server_observe_organizer_message(...)` uses identical observer arguments.
- `server_acknowledge_organizer_message_worker()` → boolean, refreshes worker health only when configured/enabled.
- `server_configure_organizer_messages(p_configuration jsonb)` → boolean; exact keys acceptingSends,workerEnabled,senderEmail,replyTo,appOrigin,mediaOrigin,templateVersion,capacityPerMinute,capacityPerDay,capacityPerMonth,healthMaxAgeSeconds, maxRecipients,eventHour,eventDay,organizerDay,deliveryDay,recipientDay,previewMinute. Configuration updates are partial. Enable requires all valid capacity/configuration values; defaults remain disabled. This is an operational service contract, never browser accessible.
- `server_prune_organizer_message_history()` → number of message content rows purged. 90-day terminal retention; durable request receipt/hash and observation/suppression evidence retained.

Errors: UNAUTHORIZED, EVENT_UNAVAILABLE, EVENT_CANCELLED, EVENT_DRAFT, MODERATION_BLOCKED, INVALID_SCHEDULE, SEND_WINDOW_CLOSED, INVALID_SELECTOR, INVALID_TIER, INACTIVE_INDIVIDUAL, AUDIENCE_UNAVAILABLE, INVALID_SUBJECT, INVALID_BODY, NO_RECIPIENTS, PREVIEW_CHANGED, REQUEST_CONFLICT, LIMIT_REACHED, PREVIEW_LIMIT_REACHED, EMAIL_UNAVAILABLE. Membership drift uses PREVIEW_CHANGED (opaque combined HMAC; caller always re-previews).

Capacity allocation defaults NULL, gates false; service health freshness and all numeric limits required for new confirmation. Confirmed messages remain durable after shutdown. Dispatch prioritizes any ready/leased transactional work and reserves minute/day/month capacity under one advisory lock, with at most one leased organizer delivery. Template default `organizer-message-v1`. Optional imagery uses configured mediaOrigin and existing anonymously permitted event-images/organizer-media endpoints, otherwise null; safe public event CTA only.

Preview admission is serialized per actor and debited before validation/resolution. Expected domain failures are caught inside a nested DB subtransaction and returned; the debit remains in the enclosing RPC transaction. More than the configured requests per minute returns `{error:{code:"PREVIEW_LIMIT_REACHED"}}` without scanning/debiting further. Unauthorized callers receive no debit. Unexpected database errors still propagate and roll back. Relevant active incoherent sources fail the selected scope with AUDIENCE_UNAVAILABLE; ordinary inactive/refunded sources remain exclusions.
