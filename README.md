# WhereTo
Event Platform. 

## Try the buyer flow locally

Run `pnpm dev:seed` once, then `pnpm dev`. Open [the development hub](http://127.0.0.1:3000/preview) and choose **Open live buyer flow**. No buyer or organizer login is needed. Use `pnpm dev:reset` to replenish fixture capacity while retaining purchase history.

See [the development-world runbook](Docs/runbooks/dev-buyer-test-world.md) for prerequisites, Stripe TEST instructions, safety boundaries and removal guidance.
